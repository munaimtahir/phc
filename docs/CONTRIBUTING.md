# CONTRIBUTING.md

## Development Style
- Keep changes small.
- Run tests before committing.
- Update `copilot_session.md` during AI-agent work.
- Do not add features outside the blueprint without explicit approval.
- Keep templates simple and usable.

## Commit Examples
```text
feat: add evidence requirement model
fix: correct indicator score calculation
test: add missing evidence report tests
docs: update PHC tracker blueprint
```
