# Goals.md

## MVP Goal
Create a working tracker that imports 118 indicators, displays them, tracks evidence requirements, uploads evidence, maintains registers, and shows inspection readiness.

## v1.0 Goal
A non-technical lab manager can track all PHC indicators, see missing evidence, upload/link evidence, maintain digital registers, identify overdue recurring compliance, print a surveyor pack index, and generate safe AI prompts.

## Non-Goals
Generic accreditation platform, multi-lab SaaS, CAPA-heavy workflows, live AI document generation, complex analytics.
